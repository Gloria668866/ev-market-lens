# 懂车帝销量榜 API 字段清单（实测）
# 探针时间：2026-05-22
# 数据源：GET https://www.dongchedi.com/motor/pc/car/rank_data
# 参数：rank_data_type=11（销量榜）, new_energy_type=0/1/2/3, month=YYYYMM
# 返回格式：JSON

## 根级结构
{
  "data": {
    "list": [ ... ],     // 车系数组
    "total": 199,         // 总车系数（当月该能源类型）
    "page": 1
  }
}

## list[] 元素字段（一条车系月度销量记录）

| 字段名 | 类型 | 说明 | 示例 |
|--------|------|------|------|
| series_id | int | 车系唯一标识 | 8465 |
| series_name | str | 车系名称 | "小米SU7" |
| brand_id | int | 品牌标识 | 156 |
| brand_name | str | 品牌名称 | "小米汽车" |
| count | int | 月度销量（台） | 28506 |
| rank | int | 当期排名 | 5 |
| last_rank | int | 上期排名（0=新上榜） | 3 |
| min_price | str | 指导价下限（万元字符串） | "21.59万" |
| max_price | str | 指导价上限 | "29.99万" |
| dealer_price | str | 经销商成交价区间 | "20.59-28.99万" |
| has_dealer_price | int | 是否有经销商价 | 0/1 |
| descender_price | str/float | 降价幅度 | "1.00万" |
| car_review_count | int | 累计口碑数 | 2358 |
| image_url | str | 车系图片 | "https://..." |
| sub_brand_id | int | 子品牌ID | 0 |
| sub_brand_name | str | 子品牌名称 | "" |

## new_energy_type 枚举
- 0 = 全部
- 1 = 纯电（BEV）
- 2 = 插电式混合动力（PHEV）
- 3 = 增程式电动（EREV）

## 数据量估算（2024-01 ~ 2026-04）
- 单月新能源在榜 ≈ 199 车系
- 3种能源类型(纯电/插混/增程) × 28个月 ≈ 约8000行事实记录
- 不取 new_energy_type=0（全部），会和纯电等有大量重复
