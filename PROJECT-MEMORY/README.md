## 30 秒事实

- **产品**：车市镜 / EV-MarketLens，新能源汽车市场情报对话式 Agent。
- **求职目标**：服务 2027 届毕业生在 2026 年参加秋招，主投大模型应用、Agent 工程、AI 后端/平台工程。
- **Agent 图**：LangGraph 13 节点，五种意图为 `sql / rag / hybrid / clarify / chat`。
- **双脑**：Text2SQL 查询销量星型模型；RAG 检索报告、政策和用户上传资料。
- **本地 RAG**：SQLite + numpy，同步入库，面向小语料演示。
- **生产 RAG 配置**：PostgreSQL + pgvector、MinIO、Redis + Celery。
- **RAG 检索**：父子块、向量/关键词 RRF、BGE reranker、证据门控、父块归并和 typed 引用。
- **文档解析**：当前 `PARSER_BACKEND=lite`；MinerU 只是预留，未接入。
- **采集**：销量主链路使用公开 JSON API 和 Python 标准库 HTTP，校验源站真实发布月，幂等补缺并刷新最近两个完整月。
- **数据快照**：截至 2026-07-29 为 `202401–202606`、8402 条；7 月尚未发布，静默回退数据被拒绝。
- **生产门禁**：生产默认关闭公开注册；问题接受时原子占用账号日配额；三个问答入口共享每进程有界容量。
- **评测**：Text2SQL 固定 60 题回归集 60/60；Intent 常见路由固定集 110/110，全部走确定性规则、0 次模型调用（不代表 LLM 兜底泛化）；RAG 以最新本地确定性报告为准，不外推到生成质量或生产 PG。
- **部署**：生产配置已具备，真实云服务器 fresh-volume E2E 尚未完成。
